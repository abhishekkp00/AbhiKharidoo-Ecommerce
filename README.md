## Tech Stack

### Frontend
- **React** - UI library

- **Axios** - HTTP client
- **CSS** - Styling

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/abhishekkp00/AbhiKharidoo-Ecommerce.git
cd AbhiKharidoo-Ecommerce
```

2. Navigate to the Frontend folder:
```bash
cd Frontend
```

3. Install dependencies:
```bash
npm install
```

### Running the Application

Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173` (or the port shown in your terminal).

### Building for Production

```bash
npm run build
```
